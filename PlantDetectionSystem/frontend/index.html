📐 Evaluation Formulas

Accuracy = (TP + TN) / (TP + TN + FP + FN)

Precision = TP / (TP + FP)

Recall / Sensitivity = TP / (TP + FN)

F1 Score = 2 × (Precision × Recall) / (Precision + Recall)

About PlantCare

PlantCare is an AI-based plant identification and crop disease detection system. Users can upload an existing plant leaf image or capture a new image using the camera. The image is sent to the Flask backend where the trained AI model analyzes it and returns the plant name, disease, confidence score, condition information and basic treatment recommendations.
